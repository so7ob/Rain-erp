# تعريب Rain-erp

تتابع [Issue #15](https://github.com/so7ob/Rain-erp/issues/15) التعريب الكامل، وتخص [Issue #16](https://github.com/so7ob/Rain-erp/issues/16) البنية الأساسية والكتالوج المشترك. وجود العربية في قائمة اللغات لا يثبت اكتمال تعريب الوحدات.

## القرارات المعتمدة

- العربية الفصحى افتراضية عند غياب اختيار صالح؛ يحفظ اختيار المستخدم السابق للإنجليزية أو الصينية.
- الأرقام `0–9` والتقويم ميلادي. تبقى العملات والمبالغ والتوقيت وقواعد الأعمال كما هي.
- العربية `rtl` والإنجليزية والصينية `ltr`؛ يحتاج كل تخطيط ومكوّن قبولًا بصريًا مستقلًا.
- بيانات المستخدم والأسماء المخصصة لا تترجم تلقائيًا ولا تستبدل في قاعدة البيانات.
- تشمل الخطة الوحدات الاختيارية دون تفعيلها في التطبيق المشغّل.

## الكتالوجات وتبديل اللغة

توجد الكتالوجات في `frontend/src/locales/{ar,en,zh-CN}/`. يحتوي `shared.json` النصوص المشتركة؛ تضاف ملفات الوحدات مثل `erp.json` بمفاتيح دلالية تحت اسم الوحدة، مثل `erp.product.name`. يحمّل التطبيق اللغة المطلوبة عند الحاجة، ويحمل الإنجليزية للاحتياط. تكرار المفتاح بين الملفات خطأ.

يضاف كل مفتاح ومعاملاته إلى اللغات الثلاث. لا يقبل مفتاح عربي مفقود أو فارغ اعتمادًا على اللغة الاحتياطية. تطابق المفاتيح المشتركة لا يعني استخراج جميع النصوص الثابتة.

تحدّث آلية التبديل رسائل Vue وElement Plus واتجاه المستند والاختيار المحفوظ دون إعادة تحميل الصفحة. لا يستبدل انتهاء تحميل لغة قديمة اختيارًا أحدث. تحويل العناوين والتسميات الملتقطة مرة واحدة عند إنشاء الشاشات إلى قيم تفاعلية جزء من دفعات تلك الشاشات.

تعتمد صيغ الوقت النسبي على `Intl.RelativeTimeFormat` بما يشمل المثنى والجمع، مع أرقام لاتينية. ترسل طلبات Axios، بما فيها تجديد الجلسة، اللغة الحالية في `Accept-Language`. ترجمة رسائل الخادم مرحلة لاحقة؛ إرسال الرأس وحده لا يثبت تعريب API.

## الحصر والقبول

```bash
cd frontend
corepack pnpm test
corepack pnpm i18n:inventory
corepack pnpm i18n:check
node scripts/localization-inventory.mjs --details
corepack pnpm i18n:accept
```

يحفظ الحصر الملخص في `docs/localization-inventory.json`، ويطابقه الفحص مع المصدر والكتالوجات. يطبع `--details` النصوص المرشحة ومواضعها، دون إعدادات التشغيل أو بيانات المستخدم. يكشف المحلل نصوص قوالب Vue وخصائص العرض والتعبيرات والنصوص السياقية في JavaScript وTypeScript. أعداد Java حصر للملفات وثوابت الأخطاء ورؤوس Excel ورسائل التحقق فقط.

النصوص المنشأة وقت التشغيل، وCSS، والصور، والمكونات الخارجية ومخرجات الخادم الديناميكية تحتاج مراجعة مستقلة. تبقى أخطاء تحليل القوالب ظاهرة. جميع الوحدات في حالة `pending-acceptance`؛ يفشل `i18n:accept` صراحة حتى استكمال القبول تحت #15. أعداد المواضع ليست نسبة إنجاز أو عدد نصوص فريدة.

يتطلب قبول كل وحدة استخراج النصوص ومراجعتها لغويًا، واختبار القوائم والقواميس والبيانات المخصصة وAPI والصلاحيات، والاستيراد والتصدير والطباعة عند وجودها، والمتصفح ولوحة المفاتيح وaxe والنص المختلط وعرضي `375` و`1280` والمظهرين الفاتح والداكن. توثق الثوابت التقنية المستثناة حسب الموضع والسبب. تتحقق الوحدات الاختيارية في بيئة معزولة؛ بناء النظام والبنية التحتية لا يغطيها.

## قاموس المصطلحات

| المفهوم | المصطلح العربي |
| --- | --- |
| Tenant | المنشأة، عندما يشير إلى مساحة المؤسسة في الواجهة |
| User / role / permission | مستخدم / دور / صلاحية |
| Product / item | منتج / صنف بحسب السياق |
| Inventory / warehouse | مخزون / مستودع |
| Purchase order / sales order | أمر شراء / أمر بيع |
| Stock receipt / issue | إدخال مخزني / إخراج مخزني |
| Customer / supplier | عميل / مورد |
| Account / journal / voucher | حساب / يومية / سند، بحسب السياق المحاسبي |
| Debit / credit | مدين / دائن |
| Approve / reverse approval | اعتماد / إلغاء الاعتماد |
| Status / enabled / disabled | حالة / مفعّل / معطّل |
| Export / import / upload | تصدير / استيراد / رفع |
| Dictionary / dictionary value | قاموس / قيمة القاموس |

تبقى أسماء المنتجات والعلامات والمعرّفات مثل `OAuth 2.0` كما هي. تراجع المصطلحات المحاسبية في سياق الشاشة والمخرجات، ولا تستبدل الكلمات آليًا في بيانات المستخدم.

## التكاملات والدفعات المتبقية

- **JimuReport وJimuBI:** تأتي واجهاتهما من اعتماد Java داخل iframe؛ يشمل العمل الغلاف وتمرير اللغة المدعومة، وتسجل نتيجة دعم العربية الفعلية لكل مصمم.
- **GoView:** خدمة منفصلة لا يوجد مصدرها هنا؛ تترجم الواجهة المملوكة وتمرر اللغة حيث تدعمها الخدمة، وتسجل الواجهة الخارجة عن السيطرة.
- **روابط التوثيق والخدمات الخارجية:** يترجم عنوان الرابط؛ محتوى الموقع الخارجي خارج مصادر المستودع.
- **المحررات ومصممو النماذج والمخططات المستوردة:** تحتاج محولات عربية داخل المشروع وقبول RTL مستقلًا عن كتالوج Vue.

تغطي الدفعات التالية النواة والشاشات المشتركة، ورسائل الخادم، والقوائم والقواميس، ثم وحدات الأعمال وبقية الوحدات، ثم قبول المخرجات والمتصفح. تبقى #15 مفتوحة حتى اكتمالها. نشر التطبيق وتفعيل الوحدات وتعديل بيانات التشغيل أعمال منفصلة.
