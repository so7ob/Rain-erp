# Rain-erp

**العربية** | [English](README.en.md)

سياسة المساهمة والتطوير والإصدارات: [دليل المساهمة](CONTRIBUTING.md).

**Rain-erp** أحد منتجات شركة **[so7ob-tech — سحب التقنية](https://github.com/so7ob-tech)**، وهو منصة لإدارة الأعمال وتخطيط موارد المؤسسة.

> **سحب التقنية — تمطر حلولاً ذكية**

تستند المنصة إلى المشروع مفتوح المصدر **Yudao / ruoyi-vue-pro**. يقدّم هذا الدليل توثيقًا عربيًا للمنصة، مع الحفاظ على مراجع المشروع الأصلي ومخططاته وصور واجهاته.

روابط العروض التجريبية والتوثيق وفروع الإصدارات أدناه تخص المشروع الأصلي، وقد يكون محتواها بالصينية. ترجمة هذا الملف لا تغيّر لغة واجهة التطبيق.

يستهدف إعداد هذا المستودع **Java 17** و**Spring Boot 3.5.15** وفق [pom.xml](pom.xml). تُفعّل وحدتا النظام والبنية التحتية افتراضيًا مع إطار العمل والخادم؛ وتبقى وحدات الأعمال الأخرى اختيارية في إعداد البناء.

## نبذة عن المنصة

**Rain-erp** منصة من **سحب التقنية (so7ob-tech)** لإدارة الأعمال وتسريع تطوير التطبيقات، تستند إلى **Yudao / ruoyi-vue-pro**، ومتاحة للأفراد والمؤسسات وفق ترخيص MIT المرفق.

> يمكن الإبلاغ عن المشكلات واقتراح الميزات عبر قسم _Issues_ في المستودع المعني.
>
> إضافة نجمة إلى المشروع وسيلة لدعم القائمين عليه.

![مخطط البنية المعمارية](/.image/common/ruoyi-vue-pro-architecture.png)

* خلفية Java في المشروع الأصلي: يستخدم فرع `master` الإصدار JDK 8 مع Spring Boot 2.7، وفرع `master-jdk17` الإصدار JDK 17/21 مع Spring Boot 3.5، وفرع `master-jdk25` الإصدار JDK 25 مع Spring Boot 4.x.
* لوحة إدارة الويب: إصداران باستخدام Vue3 مع `element-plus` أو `vben(ant-design-vue)`، وإصدار باستخدام Vue2 مع `element-ui`.
* لوحة إدارة الجوال: تعتمد على `uni-app` لتشغيل قاعدة شيفرة واحدة كتطبيق جوال أو تطبيق مصغّر أو واجهة ويب H5.
* الخلفية مبنية على Spring Boot متعدد الوحدات، مع MySQL وMyBatis Plus، وRedis وRedisson.
* تدعم قواعد البيانات MySQL وOracle وPostgreSQL وSQL Server وMariaDB، إضافة إلى DM وKingbaseES وHighGo وغيرها. راجع [التوافق ودعم قواعد البيانات](#database-support).
* تشمل خيارات الرسائل والأحداث Event وRedis وRabbitMQ وKafka وRocketMQ.
* تعتمد المصادقة على Spring Security والرموز وRedis، مع دعم أنواع متعددة من المستخدمين والأجهزة وتسجيل الدخول الموحّد SSO.
* تحميل ديناميكي لقوائم الصلاحيات، وتحكم على مستوى الأزرار، وتخزين مؤقت باستخدام Redis لتحسين الأداء.
* دعم تعدد المستأجرين لتطبيقات SaaS، مع تخصيص صلاحيات كل مستأجر ومعالجة العزل في طبقة البنية التحتية.
* يستخدم سير العمل Flowable، ويدعم النماذج الديناميكية والتصميم المرئي وموافقة الجميع أو أحد المراجعين وطرقًا متعددة لتوزيع المهام.
* يولّد مولّد الشيفرة ملفات Java وVue ونصوص SQL وتوثيق الواجهات، مع دعم الجداول المفردة والشجرية وعلاقات الرئيسي والتفاصيل.
* اتصال فوري باستخدام Spring WebSocket، مع التحقق من الرموز ودعم عناقيد WebSocket.
* تكامل تسجيل الدخول مع تطبيقات WeChat المصغّرة وحساباته العامة وWeCom وDingTalk، وتكامل الدفع والاسترداد مع Alipay وWeChat.
* تكامل الرسائل النصية مع Alibaba Cloud وTencent Cloud، والتخزين مع MinIO وAlibaba Cloud وTencent Cloud وQiniu Cloud.
* مصممان للتقارير ولوحات عرض البيانات، مع الإنشاء بالسحب والإفلات.

## التوافق ودعم قواعد البيانات

يدعم المشروع أنظمة تشغيل وقواعد بيانات وبرمجيات وسيطة من المنظومة التقنية الصينية، لتلبية احتياجات النشر في بيئات Xinchuang:

| الفئة | الخيارات المدعومة | ملاحظات |
| ---------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| أنظمة تشغيل صينية | توزيعات Linux مثل Kylin وUnionTech UOS | راجع [النشر على Linux](https://doc.iocoder.cn/deployment-linux/) واختر JDK متوافقًا مع معمارية المعالج. |
| قواعد بيانات علائقية | MySQL، MariaDB، Oracle، PostgreSQL، SQL Server | MySQL هو الخيار الافتراضي. |
| قواعد بيانات علائقية صينية | DM، KingbaseES، openGauss، HighGo، OceanBase، TiDB، Huawei GaussDB، MogDB، Vastbase G100، PolarDB، Shentong | راجع [قواعد بيانات Xinchuang](https://doc.iocoder.cn/xinchuang-db/). |
| أنظمة تخزين مؤقت صينية | TongRDS، BES CacheDB | بدائل Redis؛ راجع [قواعد بيانات Xinchuang](https://doc.iocoder.cn/xinchuang-db/). |
| خوادم تطبيقات صينية | TongWeb، BES AppServer | بدائل Tomcat؛ راجع [نشر TongWeb](https://doc.iocoder.cn/deployment-tong/) و[نشر BES](https://doc.iocoder.cn/deployment-bes/). |
| خوادم ويب صينية | TongHttpServer | بديل Nginx لخدمة الملفات الثابتة والوكيل العكسي؛ راجع [نشر TongWeb](https://doc.iocoder.cn/deployment-tong/). |

* يوفر مجلد [`sql`](sql/) نصوص التهيئة، بما فيها Quartz، لقواعد MySQL وOracle وPostgreSQL وSQL Server وDM وKingbaseES وopenGauss وHighGo وOceanBase. استخدم مجلد قاعدة البيانات المطابقة أولًا. تستخدم MariaDB وTiDB نصوص MySQL مباشرة؛ وتعتمد GaussDB وMogDB وVastbase G100 على نصوص openGauss؛ ويستخدم إصدار PostgreSQL من PolarDB نصوص PostgreSQL. تتطلب Shentong تعديل نصوص openGauss، بما فيها Quartz، وفق [الدليل](https://doc.iocoder.cn/xinchuang-db/#_9-神通数据库) قبل الاستيراد.
* لقواعد البيانات الأخرى أو تغييرات البنية اللاحقة، راجع أدوات التحويل في [`sql/tools`](sql/tools/README.md) ودليل [تغييرات الجداول وترقية الإصدارات](https://doc.iocoder.cn/sql-update/#_3-数据库转换). يجب مراجعة النصوص الناتجة واختبارها على قاعدة البيانات المستهدفة.

## الترخيص ومزايا المشروع

**ما الذي يقدمه المشروع؟**

1. يستخدم المشروع [ترخيص MIT](https://gitee.com/zhijiantianya/ruoyi-vue-pro/blob/master/LICENSE)، وهو متاح للاستخدام الشخصي والتجاري. يجب الاحتفاظ بإشعار حقوق النشر ونص الإذن وفق ملف [LICENSE](LICENSE) المرفق.

2. الشيفرة مفتوحة بالكامل، ما يتيح الاطلاع على التصميم المعماري للمشروع. راجع [مقارنة المشاريع مفتوحة المصدر](https://www.yuque.com/xiatian-bsgny/lm0ec1/wqf8mn).

![مقارنة المشاريع مفتوحة المصدر](/.image/common/project-vs.png)

3. يذكر الدليل الأصلي أن الشيفرة تتبع إرشادات Alibaba لتطوير Java، مع تعليقات تفصيلية، ويورد إحصاءً مرجعيًا قدره 113,770 سطر Java و42,462 سطر تعليقات؛ هذه أرقام الدليل الأصلي وليست قياسًا جديدًا لهذا المستودع.

## نبذة عن المشروع الأصلي

يؤكد مؤلف المشروع الأصلي أن جميع شيفراته مفتوحة المصدر، وأنه لا يعتزم تقديم إصدار تجاري مغلق الآن أو مستقبلًا. ويصف عمله في شنغهاي لدى إحدى كبرى شركات التقنية نهارًا، ومساهمته في البرمجيات مفتوحة المصدر ليلًا.

> «أحب كتابة الشيفرة، ولا أملّ منها».
>
> «أحب العمل على البرمجيات مفتوحة المصدر، وأجد متعتي فيه».

### خدمات فريق المشروع الأصلي

يذكر فريق المشروع الأصلي أنه يقدم خدمات تطوير تعاقدية، ويمكن التواصل معه عبر WeChat باسم **Aix9975**.

يضم الفريق، وفق وصفه، مديري مشاريع ومعماريي أنظمة ومطوري واجهات وخلفيات ومهندسي اختبار وتشغيل، لتغطية دورة تطوير المشروع كاملة.

تشمل مجالات العمل المتاجر وSCRM وأتمتة المكاتب والخدمات اللوجستية وERP والموارد البشرية والمالية وإدارة المشاريع والمحتوى والمستشفيات والمدفوعات والمراسلة الفورية وحسابات WeChat العامة وتطبيقاته المصغّرة.

## الوظائف المدمجة

يوفر المشروع وحدات أعمال متعددة لتسريع بناء الأنظمة:

![طبقات الوظائف](/.image/common/ruoyi-vue-pro-biz.png)

* الوحدات الأساسية المطلوبة: إدارة النظام والبنية التحتية.
* الوحدات العامة الاختيارية: سير العمل والمدفوعات والتقارير ومركز الأعضاء.
* وحدات حسب الحاجة: المتجر، وERP لتخطيط موارد المؤسسة، وWMS لإدارة المستودعات، وCRM لعلاقات العملاء، وCMS لإدارة المحتوى، وMES لتنفيذ التصنيع، وHRM للموارد البشرية، وFMS للمالية، وPMS للمشاريع، وOA لأتمتة المكاتب، والذكاء الاصطناعي، وإنترنت الأشياء، والمراسلة الفورية، وتطبيقات الجوال، ولوحات عرض البيانات.

>
> * تشير العلامة 🚀 إلى الميزات المضافة.
> * تشير العلامة ⭐️ إلى الميزات التي أُعيد تنفيذها.

يتضمن المشروع **اختبارات وحدات** لدعم جودة الشيفرة والتحقق من سلوك الوظائف.
